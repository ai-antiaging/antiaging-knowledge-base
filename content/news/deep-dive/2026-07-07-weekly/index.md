# CD38 代谢重编程：内皮衰老如何驱动斑块内血栓形成

> **Circulation Research** (IF≈28) | PubMed: [42200276](https://pubmed.ncbi.nlm.nih.gov/42200276/) | DOI: 10.1161/CIRCRESAHA.125.327427

---

## 📖 研究背景

动脉粥样硬化是全球头号死因。斑块破裂引发血栓形成导致的心肌梗死和缺血性中风，每年夺去数百万生命。长期以来，研究者关注的是斑块中脂质沉积和炎症反应，但**斑块内新生血管（intraplaque neovascularization）的脆化和渗漏**——被称为"斑块内出血"——同样是驱动斑块不稳定的关键事件，却缺乏深入的机制理解。

与此同时，**内皮细胞衰老**已被确认为心血管衰老的核心驱动力。衰老的内皮细胞丧失屏障功能，释放促炎因子，促进动脉粥样硬化进展。然而，一个根本问题一直悬而未决：**紊乱血流（disturbed flow，如血管分叉处的复杂血流动力学）如何在内皮细胞中触发衰老表型，并最终导致斑块内血栓形成？**

这篇发表于 *Circulation Research* 的研究，首次用空间多组学技术串联起了从血流动力学到代谢重编程再到斑块内血栓的完整因果链，并锁定了一个全新的干预靶点——**CD38**。

---

## ❓ 核心问题

这项研究试图回答三个层层递进的问题：

1. **机械血流紊乱（d-flow）如何诱导内皮细胞发生"衰老相关干性表型"？**
2. **CD38 在这一过程中扮演什么角色？它的代谢效应是什么？**
3. **靶向 CD38 能否逆转斑块内新生血管的脆化和血栓倾向？**

## 🧪 方法与技术亮点

研究团队采用了多层次的技术体系：

| 技术 | 用途 |
|------|------|
| **空间转录组学 + 空间代谢组学** | 在组织原位解析内皮细胞的基因表达和代谢状态 |
| **LATS1/2 条件性敲除小鼠** | 模拟紊乱血流对内皮 Hippo 通路的抑制效应 |
| **CD38 药理学抑制** | 验证 CD38 作为可药物化靶点的可行性 |

**技术亮点：** 空间多组学的引入是本研究的方法学创新。传统的 bulk RNA-seq 或单细胞测序虽然能解析细胞异质性，但丢失了空间位置信息。而本研究在斑块组织原位同时获取基因表达和代谢物分布，直接揭示了 CD38 高表达内皮细胞的空间定位与其周围微环境代谢重塑的关联。

## 📊 关键发现

### 发现一：LATS1/2 缺失 → CD38 上调 → 衰老相关干性表型

研究首先确认，紊乱血流（d-flow）通过抑制 Hippo 通路核心激酶 **LATS1/2**，诱导内皮细胞中 **CD38** 的表达显著上调。CD38 是一种 NAD⁺ 糖水解酶，在衰老生物学中已有一定知名度——它被认为是驱动年龄相关 NAD⁺ 下降的关键因子之一。

但本研究的重要突破在于：**CD38 的上调不仅消耗 NAD⁺，更触发了一种"衰老相关干性表型"（senescence-associated stemness phenotype）**。这种表型使内皮细胞获得类似干细胞的增殖能力，但丧失了正常内皮的屏障功能和成熟标志物表达。

### 发现二：CD38 抑制 SUOX → 线粒体复合物 V 反向运行 → ATP 危机

这是本研究最核心的机制发现。研究团队通过空间代谢组学揭示了一条前所未有的代谢通路：

```
CD38 ↑ → 亚硫酸盐氧化酶（SUOX）↓ 
       → 线粒体复合物 V（ATP合酶）反向运行
       → 琥珀酸脱氢酶（SDH）活性 ↑
       → ATP 大量消耗 + 代谢通量重定向
```

这一链条的意义在于：

- **线粒体复合物 V 反向运行**：正常情况下，ATP合酶利用质子梯度合成 ATP。但在这条通路中，它被"倒转"——消耗 ATP 来维持质子梯度。这意味着细胞在"烧钱维持门面"，而非正常产能。
- **SDH 活性升高**：琥珀酸脱氢酶是线粒体呼吸链复合物 II，也是三羧酸循环的关键酶。其活性升高提示代谢通量被重定向，以支撑异常的内皮增殖。
- **谷氨酸代谢和 TCA 通量维持**：尽管 ATP 合成受损，细胞仍维持核心代谢通量——这正是"干性表型"的代谢特征：不惜代价维持增殖能力。

### 发现三：药理学抑制 CD38 可显著减轻斑块内血栓表型

研究最后证明了干预的可行性：使用 CD38 抑制剂处理后，内皮细胞的衰老相关干性表型显著减轻，斑块内新生血管的脆化和渗漏减少，血栓形成倾向降低。

**这一发现的临床意义在于：** CD38 已有多款抑制剂在血液肿瘤领域进入临床开发阶段（如 daratumumab 的类似物）。虽然现有药物主要是抗体而非小分子，但 CD38 作为靶点的"可药物化"（druggability）已经得到验证。

## ⚠️ 局限性与未解问题

作为一篇机制研究，本文也存在若干局限：

1. **缺乏人体直接证据：** 所有核心实验均在动物模型和细胞水平完成。虽然 CD38 在人类衰老内皮中的表达已有文献支持，但本研究揭示的 CD38→SUOX→线粒体复合物 V 反向运行的通路尚需在人体样本中验证。

2. **CD38 抑制剂的特异性问题：** 研究使用的 CD38 抑制剂是否会影响 CD38 在其他组织中的正常功能（如免疫调节）尚未充分讨论。系统性 CD38 抑制可能带来免疫抑制等副作用。

3. **时间维度缺失：** 研究呈现的是机制的"快照"，但衰老是一个动态过程。CD38 上调是衰老的因还是果？它在衰老的不同阶段是否扮演不同角色？这些问题需要纵向研究来回答。

4. **LATS1/2 的多效性：** LATS1/2 是 Hippo 通路的核心组分，其缺失影响的不仅仅是 CD38。研究中观察到的表型有多少归因于 CD38，多少归因于 Hippo 通路的其他下游效应，仍有待更精细的遗传学实验（如 CD38 特异性回补）来区分。

## 💡 对领域的意义

### 1. 为心血管衰老提供了可操作的靶点

CD38 作为衰老相关 NAD⁺ 下降的关键驱动因子，此前主要被视为一种"衰老标志物"。本研究首次将其定位到**具体的病理因果链**中：从血流动力学到代谢重编程再到临床事件（斑块内血栓）。这意味着 CD38 抑制剂可能不仅延缓一般衰老指标，更能直接降低心血管事件风险。

### 2. 代谢重编程是衰老干预的新前沿

本研究揭示了衰老不仅仅是"功能下降"，而是一种**主动的代谢重编程**——细胞为了维持异常状态（如干性表型），不惜改变能量代谢的基本逻辑（ATP合酶反向运行）。这一视角的转变对衰老干预策略有深远影响：单纯"补充能量"（如 NAD⁺ 前体）可能不够，需要更精准地纠正代谢通量的重定向。

### 3. 为 Senolytics/Senomorphics 提供了新思路

CD38 既是衰老细胞的标志物（消耗 NAD⁺），也是驱动衰老表型的功能性分子。靶向 CD38 可能同时实现 Senolytics（清除衰老细胞）和 Senomorphics（抑制衰老相关分泌表型）的双重效果，是"一石二鸟"的干预策略。

### 4. 空间多组学在衰老研究中的示范价值

本研究展示了空间多组学如何揭示传统方法无法发现的机制——特别是代谢物的空间分布与基因表达的原位关联。这一方法学范式有望推广到其他衰老相关研究，如脑衰老中的代谢异质性、肌肉衰老中的微环境变化等。

## 🏠 对普通人的意义

虽然这是一篇基础机制研究，但它传达的信息对普通人有直接参考价值：

- **运动的重要性再获印证：** 紊乱血流是 CD38 上调的起始触发因素。规律运动可改善血流动力学，减少血管分叉处的紊乱血流，从源头上降低内皮衰老风险。
- **NAD⁺ 补充剂的潜在价值：** CD38 是 NAD⁺ 的主要消耗者。研究结果从机制上支持了 NAD⁺ 前体（如 NMN、NR）在心血管健康中的应用逻辑，但需要注意：补充 NAD⁺ 是"加法"，抑制 CD38 是"减法"，两者策略不同，效果可能互补。
- **心血管风险评估的新维度：** 未来，CD38 水平或 SUOX 代谢物可能成为评估斑块不稳定风险的新型生物标志物。
