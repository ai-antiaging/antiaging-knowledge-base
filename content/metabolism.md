## 📊 核心代谢通路

### 1. NAD+ 代谢通路

**通路概述**：
NAD+（烟酰胺腺嘌呤二核苷酸）是细胞能量代谢和信号传导的关键辅因子，随年龄增长而下降。NAD+ 是 Sirtuins 去乙酰化酶和 PARPs DNA 修复酶的必需辅因子。

**关键节点**：
- **NMN**（烟酰胺单核苷酸）：NAD+ 直接前体
- **NR**（烟酰胺核糖）：NAD+ 前体
- **NAMPT**：NAD+ 合成限速酶
- **Sirtuins**：NAD+ 依赖性去乙酰化酶
- **PARPs**：NAD+ 依赖性 DNA 修复酶
- **CD38**：NAD+ 降解酶（随年龄增加）

**通路图**：
```
色氨酸 → Kynurenine → QA → NAD+
     ↓
烟酸 → NAMN → NAAD → NAD+
     ↓
烟酰胺 → NMN → NAD+ → NR（循环）
                ↓
          Sirtuins / PARPs / CD38
```

### 2. mTOR 信号通路

**通路概述**：
mTOR（雷帕霉素靶蛋白）是细胞生长和代谢的核心调控因子，整合营养、能量和生长因子信号。mTOR 过度激活加速衰老，抑制可延长寿命。

**关键节点**：
- **mTORC1**：雷帕霉素敏感，调控蛋白质合成和自噬
- **mTORC2**：雷帕霉素不敏感，调控细胞骨架和存活
- **AMPK**：能量感应器，抑制 mTOR
- **Insulin/IGF-1**：上游激活信号
- **S6K**：mTORC1 下游效应器
- **4E-BP1**：翻译起始调控

**通路图**：
```
Insulin/IGF-1 → PI3K → AKT ─┬→ mTORC1 → S6K / 4E-BP1 → 蛋白质合成
                            └→ mTORC2 → AKT（正反馈）
AMPK（能量低）→ ─| mTORC1（抑制）→ 自噬激活
```

### 4. AMPK 能量感应通路

**通路概述**：
AMPK（AMP 活化蛋白激酶）是细胞能量状态的主要感应器，低能量时激活，促进分解代谢，抑制合成代谢。AMPK 激活模拟热量限制效应。

**关键节点**：
- **AMP/ATP 比率**：激活信号
- **LKB1**：上游激酶
- **CaMKKβ**：钙依赖性激活
- **mTOR**：下游抑制靶点
- **PGC-1α**：线粒体生物合成
- **Sirtuins**：协同作用

**通路图**：
```
AMP↑/ATP↓ → AMPK 激活 ─┬→ ─| mTOR（抑制合成）
                       ├→ PGC-1α（线粒体生成）
                       ├→ Sirtuins 激活
                       └→ 自噬激活
```

### 5. 线粒体代谢网络

**通路概述**：
线粒体是能量生产和代谢调控中心，线粒体功能障碍是衰老的核心标志之一。

**关键节点**：
- **TCA 循环**：能量代谢核心
- **电子传递链**：ATP 生产
- **ROS 产生**：氧化应激来源
- **线粒体自噬**：质量控制
- **线粒体动力学**：融合/分裂平衡

**通路图**：
```
葡萄糖 → 丙酮酸 → TCA 循环 → NADH/FADH2
                    ↓
            电子传递链 → ATP + ROS
                    ↓
            线粒体自噬（清除损伤）
```

### 7. GLP-1 受体激动剂与代谢衰老 ⭐ 2025-2026 新增

**通路概述**：
GLP-1（胰高血糖素样肽-1）受体激动剂最初作为降糖/减肥药物开发，但 2025-2026 年的突破性研究证实其具有**抗衰老代谢调控**作用，成为连接代谢干预与衰老延缓的新兴通路。

**关键节点**：
- **GLP-1R**：广泛表达于胰腺、大脑、心脏、肾脏、肝脏、脂肪组织
- **cAMP/PKA 通路**：主要下游信号，促进胰岛素分泌
- **PI3K/AKT 通路**：改善胰岛素敏感性
- **AMPK 激活**：间接激活，模拟热量限制效应
- **炎症抑制**：降低 IL-6、TNF-α、hsCRP
- **脂肪组织重塑**：减少内脏脂肪，改善脂肪因子分泌

**抗衰老机制**（2025-2026 新认识）：
```
GLP-1 激活 ─┬→ 减少内脏脂肪 → 改善脂肪"肥胖记忆"表观遗传印记
           ├→ 降低慢性炎症 → IL-6↓, sCD163↓ → 减缓炎性衰老
           ├→ 改善胰岛素敏感性 → 降低代谢压力
           ├→ 激活 AMPK → 促进自噬和线粒体功能
           └→ 保护内皮功能 → 心血管获益
```

**2026 里程碑**：
- *Nature Communications* 2026：司美格鲁肽 32 周 RCT 首次证实**减缓表观遗传衰老**
  - PhenoAge 每年少增 **4.9 年**
  - DunedinPACE 衰老速度减缓 **~9%**
  - 11 个系统时钟同步改善（炎症、大脑、心脏最显著）
- 机制：通过 CCL2/CCR2 通路逆转脂肪组织表观遗传和代谢功能障碍

**临床意义**：
- GLP-1RA 从"降糖减肥药"拓展至"抗衰老代谢干预"
- 为代谢综合征合并加速衰老人群（如 HIV 感染者）提供新策略
- 大型 III 期试验（如 SELECT 心血管结局试验）正在进行中
